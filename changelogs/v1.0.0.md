# v1.0.0

## 新增功能

- 支持主题快捷键编辑、拖拽调整层级、框选多选、撤销重做与自动保存，提供本地草稿恢复和保存冲突处理。
- 主题可添加备注、标签、待办、任务、标记、链接、附件、图片、贴纸与 LaTeX 公式；文件夹可保留目录打包下载。
- 支持概要、边界和联系线，可编辑标题、线条样式与双向箭头，拖动控制柄调整联系走向。
- 提供 9 种布局、19 套内置配色和自定义主题，支持统一调整画布内的主题形状、字体及分支样式。
- 支持多画布新建、复制、重命名和排序；画布提供横竖滚动条、快捷缩放及保持当前缩放的中心主题定位。
- 支持画布与大纲同步编辑、ZEN 专注模式、内置模板及个人模板复用。
- 导图列表支持搜索、排序和复制，回收站支持恢复、彻底删除与按设定期限自动清理。
- 支持 XMind、Markdown、OPML 导入，以及 Markdown 文本粘贴和多文件顺序导入。
- 支持 JPEG、PNG、SVG、PDF、XMind、Markdown、OPML 导出及 .wmind 文档保存，可设置导出范围、倍率、留白和比例，默认选中 JPEG。
- 分享链接支持有效期、下载及备注权限、随机生成默认 4 位访问密码、反复查看复制密码和带密码链接预填；访客可滚动、缩放及折叠节点，刷新恢复作者保存状态，图片类导出自动保留站点品牌标识。
- 支持通过文字、Word、Excel、PDF 和图片生成并自动保存可编辑导图，可拖拽上传多份素材；管理员可配置 OpenAI 兼容 Provider 和可选思考等级，AI 功能默认关闭。
- 支持个人资料与头像维护、验证器双因素认证及恢复码，管理员可管理用户、重置密码、配置站点功能并查看业务统计和操作记录。
- 支持 S3、WebDAV 手动及定时备份、备份恢复和可搜索的时区选择；默认保留最近 30 份成功备份（含手动备份），可开启去重以跳过业务数据未变化的备份，默认每次完整备份。
- 支持中英文、浅色与深色外观，全站统一使用 W 扫光加载标识，图片加载使用浅色反馈；精简重复按钮与说明，桌面端设置紧凑排列、移动端单列展示。

## 问题修复

- 修复 Markdown 标题与列表混排时标题层级丢失，以及 XMind 节点边框和分支连线样式还原不正确的问题。
- 修复概要范围遗漏子树、嵌套重叠及清空标题无法保存，完善联系线与边界的画布选中、键盘删除和撤销恢复。
- 修复导出时标签、概要等可见文字的字体收集不完整及字重匹配问题，避免部分文字缺失或显示异常。
- 修复刷新页面时无令牌探测导致的 401；修改密码后撤销其他设备的旧会话，当前设备保持登录，后台禁用或删除用户后立即阻止其登录和公开分享访问。
- 修复备份设置接口重定向引发的加载失败与 HTTPS 混合内容拦截，以及部署后上传图片无法正常访问的问题。
- 修复分享修改密码后旧访问凭证仍可使用，以及并发修改分享设置可能恢复旧密码的问题。
- 修复私有图片与缩略图可能被匿名或其他用户读取的问题；分享图片随链接改密、撤销、到期和账号停用即时失效，公开头像保持正常展示。
- 阻止跨站请求更改登录会话，避免分享图片的临时访问凭据进入访问日志或导出文件。
- 修复反向代理下访客限流互相影响及伪造客户端地址绕过限制的问题，收紧普通请求和慢速上传的资源占用边界，保留管理员备份恢复的独立上传额度。

## 性能改进

- 大导图仅绘制可视区域及必要交互对象，减少滚动和键盘导航时的渲染开销。
- 网站使用从原始 Logo 生成的轻量图片，将图片体积从约 52 KB 缩减至约 12 KB。
