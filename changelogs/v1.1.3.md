# v1.1.3

## 新增功能

- 桌面端新增 Linux 版本：提供 Debian / Ubuntu 的 `.deb`、其他发行版的 tar.gz + `install.sh`，以及 Arch 的 `PKGBUILD`。
- 桌面端日志支持滚动（单文件 5 MiB、保留 5 份），并记录启动信息、客户端接口调用与云端连接过程；日志级别可用环境变量临时调细。
- 桌面端启动失败时会弹窗说明原因并给出日志路径，不再出现「双击没反应、也没有任何报错」。
- 桌面端首次同步与云端缩略图：同步下来的导图直接带缩略图，无需先打开一次。

## 问题修复

- 修复 Windows 版启动即退出的问题（备份服务的跨进程维护锁在 Windows 上没有实现），并预检 WebView2 运行时缺失的情况。
- 修复全新安装后第一次同步必定失败的问题（增量同步起点为空被当作参数错误）。
- 修复登录或连接服务器失败时只显示「连接失败」、看不出真实原因的问题；现在会给出地址、状态码与底层原因。
- 修复桌面端访问令牌过期后同步与设置直接失败的问题；现在会自动刷新并重试。
- 修复 Windows 上窗口右上角的最小化 / 最大化 / 关闭按钮压住顶栏操作区的问题。
- 修复同步后导图的修改时间变成同步时刻、以及仅打开查看也会更新修改时间的问题。
- 修复导图缩略图显示为问号、不铺满卡片，以及云端导图没有缩略图的问题。
- 修复主题文字垂直不居中、编辑主题时输入框不随内容变大的问题。

## 性能改进

- 桌面端界面字体改为系统字体优先，整页重排从 375ms 降到 21ms，弹窗与下拉几乎即时打开。
- 桌面端更新支持增量补丁，升级不再每次下载完整安装包。
