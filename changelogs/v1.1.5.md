# v1.1.5

## 新增功能

- 新增 MCP（Model Context Protocol）支持，Claude Desktop 等 AI 客户端可以直接查询、新建和修改导图：
  - 桌面端默认走 stdio：随应用分发 `wmind_mcp` 助手，客户端配置里只填一条不带空格的路径，不占端口、不需要密钥；也可切换为 HTTP 监听端口并使用访问密钥。
  - 服务器在「网站设置 → MCP」开启 `/mcp` 端点，用密钥授权，AI 只能操作开启它的那个管理员自己的导图。
  - 提供 7 个工具：列出导图、读取结构、新建导图（缩进大纲）、修改标题、新增子主题、修改任意主题文字、删除主题。
  - 两处均默认关闭，可一键复制客户端配置；密钥可随时轮换，旧密钥立即失效。
- 桌面端隐藏窗口级滚动条、内部滚动条细化，观感更接近原生应用。

## 问题修复

- 修复 Windows 上 Ctrl+滚轮或触控板捏合会把整个界面（含顶栏文字）一起缩放的问题。
- 修复滚轮在画布之外的区域仍会缩放或平移画布的问题。
- 修复免安装 zip 里嵌套了安装包导致体积翻倍的问题。
