# v1.1.0

## 新增功能

- 新增桌面客户端（macOS Apple Silicon / Intel、Windows x64 / ARM64）：内置同一套后端，断网也能完整编辑、导入导出、使用主题模板，数据保存在本机。
- 桌面端可连接自托管服务器：导图带「本地 / 云端」标识，本地图可上传云端，删除状态双向同步；两端都改过同一张图时提供保留我的 / 放弃我的 / 另存副本三种处理。
- 桌面端支持登录云端并显示账号昵称与头像，支持两步验证（动态码或恢复码），记住上次的服务器与账号，登录后自动同步。
- 桌面端「网站设置」在客户端内直接读写服务器配置，登录云端后分享功能归服务器管理（创建、撤销、改密码与有效期）。
- 桌面端新增关于弹窗（项目介绍、版本、检查更新、项目地址、部署说明）、快捷键速查，启动时自动检查更新并在有新版时提示。
- 桌面端跟随系统语言，界面提供浅色与深色外观，支持无系统标题栏的窗口顶栏。
- 新增本地目录备份目标，桌面端可离线配置备份；新增增量同步接口与客户端幂等标识，供桌面端同步使用。
- 站点品牌名统一为 Wmind，桌面端安装包、窗口与导出落款保持一致。

## 问题修复

- 修复桌面端打开弹窗与下拉需要等待一秒的问题：界面字体改为系统字体优先，并在 WebKit 上关闭整屏模糊。
- 修复主题文字垂直方向不居中，以及新建导图的占位文案不跟随界面语言。
- 修复导图缩略图显示为问号、未铺满卡片以及图片加载失败时缺少提示。
- 修复云端登录失效时被误判为本机登录过期而退出到登录页。
- 修复登录后首次同步阻塞登录响应、同步完成后列表不刷新，以及同步后导图的修改时间变成同步时刻。
- 修复退出登录与删除自定义配色缺少二次确认，桌面端菜单出现滚动条且滚轮会穿透到画布。
- 修复桌面端在浅色图片上显示破图图标、导入导出的字体与缩略图不一致问题。

## 性能改进

- 桌面端界面文字改用系统字体并关闭 WebKit 上的整屏模糊后，整页重排从 375ms 降到 21ms，弹窗与下拉几乎即时打开。
- 下拉弹层按最宽选项自适应宽度，打开时在一帧内完成定位，避免先出现空弹层。
