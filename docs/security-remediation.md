## 部署注意与验收用例

- 所有服务实例必须同步更新，旧实例仍可能按旧权限逻辑放行。已下发到客户端的图文无法远程收回。
- 默认 Compose 新增专用网络与固定地址，现有部署需要重建网络，可能短暂中断；不能删除数据卷。地址冲突时同时配置示例中的子网和各服务地址，不能改成信任全部私网或公网。
- 分享访客的旧凭据需要重新验密；无法在任何既有导图或模板中证明归属的旧图片必须重新上传，不恢复永久公开直链。
- 旧图片和分享图片授权有文档扫描开销，大图多图片需观察 CPU；后续资产索引不能牺牲即时撤权。

浏览器/预发布验收：

1. 属主打开旧图、模板和新上传图片，缩略图与 JPEG/SVG/XMind 导出正常；匿名和其他账号访问相同私有图片均 404，头像仍可公开显示。
2. 打开有密码分享，再修改密码、撤销链接、停用属主或删除导图；下一次文档及图片请求均拒绝。Markdown/SVG 下载和访问日志中不得包含临时访问凭据。
3. 两设备登录后改密，当前设备继续工作，旧设备访问/刷新失败且不影响当前新会话；输错旧密码不能退出当前登录。
4. 通过实际反向代理分别耗尽两名访客配额，互不影响；伪造 XFF 不能重置配额。跨站表单不得创建或清理认证 Cookie。
5. 匿名请求恢复上传入口立即拒绝，不先缓冲完整大文件；合法管理员恢复保持独立上传额度，备份根接口仍不得重定向到 HTTP。
