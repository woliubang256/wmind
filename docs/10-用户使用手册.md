## 1. 登录与账号

### 登录

用**用户名或邮箱**都能登录，密码区分大小写。

连续输错密码 5 次，账号会锁 15 分钟（管理员可改这两个数字）。锁定期内即使密码
正确也会被拒绝——这是防止暴力猜测，不是账号出问题。

### 双因素登录

在「个人设置 → 双因素认证（2FA）」启用后，密码正确还需要输入验证器中的六位验证码。可以使用 Google Authenticator、Microsoft Authenticator 或兼容的应用。

没有验证器时，点「使用恢复码」，输入设置时保存的一次性恢复码。密码步骤不会建立登录会话，第二步通过才会进入应用。验证步骤五分钟后过期；过期时返回密码登录重新开始。每个验证码和恢复码只能使用一次，刚使用过验证码时请等待下一组。

### 注册

站点开放注册时，登录页底部有「立即注册」。注册即生效，不需要邮箱验证。

**注册用户名**：3–32 位，字母、数字、下划线或短横线。
**密码长度**：至少 8 位（管理员可调高）。

如果登录页没有「立即注册」，说明管理员关闭了注册。此时直接访问 `/register`
也只会看到「本站暂未开放注册」，需要账号请找管理员开。

### 忘记密码

一期**没有自助找回**，也不需要邮箱。请联系站点管理员，在后台「用户管理」里
重置。重置后管理员会拿到一串**一次性明文新密码**，用它登录后请立刻在「个人设置」
里改掉。

### 界面语言

三档：跟随浏览器、中文、English。切换即时生效，刷新后保持。管理员看不到你选了
什么——这个偏好存在你自己的浏览器里。

三个入口：

- **登录页 / 注册页的右上角**——还没登录时就能换，这是给「看不懂当前语言」的人
  准备的：那一页的语言选择器按一下 `Tab` 就能到，不用先读懂表单；
- **个人设置 → 语言**——登录之后，带一句说明（「只影响这台设备上的界面文字」）。
- **登录后的右上角顶栏**——编辑导图或管理站点时也能随时切换，刷新后保持。

语言名永远用**该语言自己的写法**（中文 / English），只有「跟随浏览器」跟着当前
界面语言变。站点名称、导图内容不会被翻译——它们是数据，不是界面文案。

## 2. 导图列表

登录后落在「最近」。这里是你的全部导图，按最近修改倒序。

| 操作 | 说明 |
| --- | --- |
| 搜索 | 按标题搜索，输入即筛 |
| 排序 | 最近修改 / 按名称 / 最近创建 |
| 新建导图 | 建一张空白导图，或先选模板 |
| AI生成 | 从文字与附件生成可编辑导图，仅管理员启用后显示 |
| 导入 | 把 XMind / Markdown / OPML 文件拖进页面，或点「导入」选文件 |
| 重命名 | 只改标题，不动内容 |
| 复制 | 连文档一起复制成一张新导图，两者从此互不影响 |
| 分享 | 打开分享对话框（见 [第 9 节](#9-分享)） |
| 删除 | 移到回收站，可以再恢复 |

每张卡片显示缩略图、节点数与更新时间。缩略图在打开导图时按需生成：还没有缩略图
的会立刻补一张，改过内容的要等下次打开——同一会话里最多每 3 分钟生成一次，免得
一次编辑往磁盘里灌几十张几乎一样的图。所以刚改完回到列表，卡片可能还是旧样子，
这是正常的。

「加载更多」按页追加，不是无限滚动。

### AI 生成

点「新建导图」左侧的「AI生成」，输入要求、点击上传或将多份素材拖入弹窗，也可以组合使用；拖入时上传区域高亮，松开后添加文件。点击「生成导图」后自动保存为一张新导图并进入编辑器，不覆盖已有文件。

- 支持 TXT/Markdown 等文本文件、`.docx`、`.xlsx`、PDF、PNG、JPEG、WebP、GIF，最多 5 份附件，每份 20 MB，合计 30 MB。
- 文本格式包括 `.txt`、`.md`、`.markdown`、`.csv`、`.tsv`、`.json`、`.yaml`、`.yml`、`.xml`、`.log`、`.ini`、`.conf`、`.toml`，保留原文与文件顺序。支持 UTF-8、带 BOM 的 UTF-16 和常见 GBK 中文；其他旧编码请先另存为 UTF-8。
- 文字合计最多 10 万字符；每份 PDF 最多 20 页，扫描页与图片合计最多 12 张。图片会压缩后发送，动画仅取第一帧。
- Word、Excel 提取正文与单元格，不复原版式或内嵌图片；PDF 优先提取文字，无文字页面转为图片。扫描 PDF 和图片需要 Provider 所选模型支持视觉。
- 生成结果最多 500 节点、12 层。AI 可能遗漏或误解内容，生成后请检查；无效结果不会保存为空导图，可保留素材重试。保存失败可「重试保存」，不会重新调用 AI。

文字与附件内容发送给站点配置的 AI Provider；不要上传无权发送的敏感材料。解析和生成阶段可取消，取消不创建文件；保存阶段短暂禁止关闭。

## 3. 模板

「模板」页分两块：

**基本模板（8 个内置）**——思维导图、逻辑图、括号图、组织架构图、树状图、
时间轴、鱼骨图、树型表格。它们**只读**，点一下就用它建出一张新导图，进去就能改。

内置模板的预览是实时渲染的真实文档，不是图片，所以看到的骨架就是建出来的样子。

**我的模板**——把当前导图存成起点：

1. 打开一张导图，点顶部工具栏的「另存为模板」按钮（在齿轮图标右边）。
2. 起个名字（1–64 字）。

存下来的模板会连**缩略图**一起复制。之后改原导图不会影响模板，改模板也不会
影响已经建出来的导图。

我的模板可以重命名、删除，上限 50 个。管理员可以关闭「另存为模板」，关闭后
只剩内置模板可用。

## 4. 编辑器

### 界面分区

- **顶部工具栏**：返回、标题（直接改）、撤销/重做、独立的同级主题与子主题按钮、「＋ 插入」菜单、标记、删除所选、
  折叠/展开、缩放（−/+、复位、适应）、只读预览、分享、导出、面板开关、
  大纲开关、ZEN、保存状态。悬停或用键盘聚焦图标按钮，可查看操作说明、快捷键和不可用原因。
- **画布**：滚轮缩放；按住**空格**拖动（或按住鼠标中键拖）平移；在空白处按下
  并拖动是**框选**，松手时选中所有与选框相交的节点。
- **右侧面板**：「样式」「配色」「标记」「结构」（「演说」一期未开放）。
- **底部画布标签**：多画布时出现。

### 节点操作

| 想做什么 | 怎么做 |
| --- | --- |
| 新建子主题 | 选中节点按 `Tab`，或点独立的「新建子主题」按钮 |
| 新建同级主题 | 按 `Enter`，或点独立的「新建同级主题」按钮；根主题没有同级，按钮不可用 |
| 改文字 | 双击节点，或按 `F2`；`Shift+Enter` 在主题内换行 |
| 删除 | `Delete` 或 `Backspace`（连同它的子主题） |
| 折叠 / 展开 | `Ctrl/⌘ + .`，或点节点旁的小圆点 |
| 移动节点 | 直接拖到别的节点上，落点决定结果（见下） |
| 多选 | 在空白处拖出一个选框（相交即选中），或 `Ctrl/⌘ + A` 选中同级全部 |
| 撤销 / 重做 | `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z`（Windows 上 `Ctrl + Y` 也行） |

方向键按**几何位置**跳（上下左右看画布上谁最近），不是按树的层级。想按层级走：
`Ctrl/⌘ + ←` 去父节点，`→` 去第一个子节点，`↑` / `↓` 在兄弟之间切换。

### 插入内容

「＋ 插入」用于插入内容，同级主题和子主题是旁边的两个独立按钮。未选中主题时，内容项不可用；选中概要或主题与概要混合选区时，也不会默认修改中心主题。多选主题可统一设置标签、待办、贴纸、插画和图片；备注、任务、链接、附件与公式需要单选。

| 菜单项 | 使用方法 |
| --- | --- |
| 备注 | 主题右侧备注图标打开查看浮层，可继续编辑纯文本；导入的 HTML 备注也按纯文本查看和编辑 |
| 标签 | 每行一个或逗号分隔；以 badge 显示在主题框下方，多个标签自动换行；多选时替换所有选中主题的标签 |
| 待办事项 | 复选框显示在标题左侧，在画布上点击可切换完成状态 |
| 任务 | 设置负责人、进度、优先级、开始及截止日期；信息显示在主题内 |
| 链接 → 网页 | 支持 http、https、mailto、tel；点击右侧入口，在浮层中打开或编辑 |
| 链接 → 主题 | 选择同一导图的其他主题；在浮层中点「打开链接」跳转并选中目标 |
| 链接 → 本地文件 / 本地文件夹 | 选择后随导图保存，在链接浮层中下载；文件夹保存为保留目录结构的 ZIP |
| 附件 | 添加多个文件，点击文件名下载；再次打开菜单可逐个移除 |
| 贴纸 / 插画 | 从内置矢量素材中选择，点击已有素材可替换或移除 |
| 本地图片 | 上传 PNG、JPEG、GIF、WebP，单张最多 8 MiB；再次打开可替换或移除 |
| 公式 | 输入 LaTeX，预览正确后保存；点击公式可重新编辑源文本 |

待办框、标题和备注/链接入口位于同一主行。备注和链接同时存在时，右侧合并为「…」，点击浮层查看备注、打开链接或继续编辑。浮层支持 Enter/空格打开、Esc 返回和点击外部关闭；只读预览可查看与打开链接，不能修改内容。

编辑窗口里的「移除」删除该项内容，内容修改和移除支持撤销重做。附件、文件和文件夹单批最多 2 MiB、100 个文件；导图总大小上限为 8 MiB。浏览器通过下载恢复文件，无法直接打开本机路径。Zone 和录音暂未提供。

### 概要选中与联系

点击概要文字或概要框可选中；按住 Shift、Ctrl 或 ⌘ 可与主题、其他概要混合多选，框选也包含概要。选中两个对象后点「联系」，可建立概要到主题、概要到概要的联系，支持文字、样式、箭头和控制柄。双击概要或按 F2 编辑标题；删除概要时同时移除相关联系，撤销可一起恢复。概要位于完整可见子树及下级概要外侧，以留白圆弧括号概括范围；折叠后随可见范围收回。

### 联系与边界删除

单击联系线或文字选中联系；单击边界的边框或标题选中边界。按 `Delete`、`Backspace` 或点顶部「删除所选」图标即可删除，`Ctrl/⌘ + Z` 撤销。联系控制柄聚焦时也能删除整条联系。删除边界会保留里面的主题，内部主题仍能直接点击选中。

`Esc` 取消当前选中后，删除键不会继续删除刚才的附属结构。正在输入标题时，删除键只删除文字。边界还支持 Tab 聚焦后用空格或 Enter 选中。

### 主题标记与联系走向

选中主题，点顶部旗帜图标或右侧「标记」，选择优先级、任务进度、旗帜、星标、人物或符号。图标出现在主题文字前；同组新图标替换旧图标，再次点击取消。多选时统一应用；所有主题都已有同一图标时，再次点击统一移除。「清空标记」删除所选主题的全部标记，支持撤销重做。固定宽度过窄时，图标会换行到标题上方。

单击联系线显示控制柄，拖动两个曲线控制柄可分别调整两端曲率，折线控制点可改变转折位置；直线拖动后变为曲线。方向键移动控制柄，按住 Shift 可精细调整。Esc 取消当前拖动，松手后的一次调整可一次撤销。在「结构」面板点「恢复自动走向」可还原。

### 拖动节点

拖动时落点决定发生什么：

| 指针落在 | 结果 |
| --- | --- |
| 目标节点的**上 25%** | 插到它**前面**（同级） |
| 目标节点的**中间 50%** | 成为它的**子主题**（追加到末尾） |
| 目标节点的**下 25%** | 插到它**后面**（同级） |
| 离所有节点都很远 | 脱离树，变成一个**自由主题** |

拖到自己的后代节点上会被拒绝（那会把分支拖成一个环），根主题不能被拖走。

### 保存

**不用手动保存。** 停止输入约 0.8 秒就会落盘；一直在打字的话，最多 5 秒也会
强制存一次。`Ctrl/⌘ + S` 可以立刻存。

工具栏的保存状态有五种，含义不同：

| 显示 | 含义 |
| --- | --- |
| 未保存 | 有改动还没发出去 |
| 保存中… | 请求在路上 |
| 已保存 HH:MM | 服务器已确认 |
| 保存失败 | 自动重试 3 次（1s / 2s / 4s）都失败，点「重试」手动再来 |
| 有冲突，待处理 | 这张导图在别处也被改了，见下 |

**冲突**发生在同一张导图被两个标签页、两台设备同时改的时候。对话框会告诉你
两边各自的版本号，然后给你三个选择：

- **保留我的版本**——用你手上的覆盖服务器，别处的修改会丢；
- **放弃我的修改**——载入服务器上的最新内容，你没存的改动会丢；
- **另存为副本**——把你的内容存成一张新导图，服务器上那张不动。

选「另存为副本」通常是最安全的。

### 本地草稿

如果你直接关掉了标签页（崩溃、断电、手滑），最近的改动还有一层保险：编辑器
每隔几秒往浏览器本地写一份草稿。下次打开同一张导图时，会提示「发现某时间的
本地修改，是否恢复？」。

草稿**保留 7 天**，之后自动作废——它是意外情况的兜底，不是版本历史。

注意草稿存在**这个浏览器**里。换设备或清了浏览器数据就找不回来了。

### 只读预览

工具栏的「眼睛」按钮进入只读预览：没有编辑能力，画布上的元素都是不可编辑的。
用来在演示或截图前确认最终效果。

## 5. 样式与配色

### 结构

「样式 → 形状与结构 · 整个画布」里可以更换当前画布的布局，共 9 种：

思维导图、逻辑图（向右）、逻辑图（向左）、树状图（向右）、组织架构图、时间轴、
鱼骨图、括号图、树型表格。

结构作用于当前画布，不影响其他画布。思维导图的主分支沿中心主题外缘分散引出，子主题使用短横线接圆角分叉；显式设置的直线、折线、无连线及线条样式仍然保留。

同一组的形状下拉统一修改当前画布的全部主题，包括中心、各级分支和自由主题；新增主题和折叠后代也会继承。可选矩形、圆角矩形、胶囊、椭圆、圆形、菱形、六边形、平行四边形、仅下划线和无形状。选择“跟随主题”恢复原有形状。形状修改不清空节点颜色、字体等其他样式，可撤销和重做。

### 配色

「配色」页管的是**整份导图**的外观（所有画布一起变），分四块：

| 块 | 内容 |
| --- | --- |
| 我的主题 | 保存当前这套外观、套用、删除 |
| 配色方案 | 19 套内置：缤纷 10 套、经典 9 套，使用分类 Tab 和两列连续色条；切换分类只浏览，点击色板才应用 |
| 全局 | 背景颜色、全局字体、分支线粗细（细 / 中 / 粗） |
| 彩虹分支 | 开启后每条一级分支取不同颜色；关闭则统一用配色方案的第一色。序列可以自己改 |

换配色不会动你手动改过的节点颜色——单个节点的样式存在节点自己身上，主题存在
文档上，两者不在同一个字段里。想让某个节点回到主题色，选中它点「重置样式」。

新图默认「缤纷 · 黎明」，中心主题白底黑字。旧图保留原来保存的完整配色；想使用新颜色，可主动选择色板。

### 自定义主题

调好配色后可以存成自己的主题，之后在别的导图里一键套用：

1. 在「配色」页顶部的「我的主题」里填名字（1–64 字）；
2. 点「保存当前」，或直接按回车。

存的是**整套外观**（配色 + 背景 + 全局字体 + 线宽 + 彩虹开关 + 布局开关），不是
只存那几个颜色——只存颜色的话，套回去会发现字体和背景没跟着变。

自定义主题上限 50 个，可以套用、删除。**没有「修改」**：要改就删掉重新存一个，
同名再存一次会得到两条同名主题。内置的 19 套不能改。

演示与压测文档不连服务器，在它们里面无法保存主题。

### 单个节点的样式

选中节点后，「样式」页可以改：

- **填充**与**边框**（颜色、宽度、实线/虚线/点线/无）；
- **文本**：字体（黑体 / 宋体 / 等宽 / 跟随系统）、字号、字重、加粗、斜体、
  下划线、删除线、文字颜色、对齐；
- **分支线条**：直线 / 曲线 / 折线 / 无连线，端点样式，线宽与线色；
- **尺寸**：默认按内容自适应，也可以指定固定宽度，超出部分自动折行。

多选（`Ctrl/⌘ + A` 选中同级全部）时改样式会一次作用到所有选中的节点。

## 6. 多画布、大纲与 ZEN

### 多画布

一张导图可以有多个画布（sheet），适合「同一个项目，不同视角」。底部标签栏：

- 点 `+` 新建画布；
- **双击**标签改名；
- **拖动**标签排序；
- 标签上的菜单可以删除画布——删错了按 `Ctrl/⌘ + Z` 能撤销。

画布之间内容独立，导出时可以选择只导当前画布还是全部画布。

### 大纲视图

工具栏的「列表」按钮打开大纲。它是画布内容的另一种呈现，两边实时同步：画布上
改一个字，大纲里立刻变。

大纲里的键盘操作：

| 按键 | 作用 |
| --- | --- |
| `Enter` | 改这一行的文字 |
| `Ctrl/⌘ + Enter` | 给这一行加子主题 |
| `Ctrl/⌘ + ]` | 降级（成为上一个兄弟的子主题） |
| `Ctrl/⌘ + [` | 升级（成为父节点的兄弟） |
| `Ctrl/⌘ + .` | 折叠 / 展开这一行 |

大纲适合快速录入：不用管布局，先把结构敲完，回画布看效果。

### ZEN 模式

工具栏的「最大化」进入 ZEN：面板、标签、多余按钮都收起来，只剩画布。再点一次
退出。适合专注写作和演示。

## 7. 导入

支持三种格式，**都在浏览器本地解析**，文件不会先上传到服务器（图片除外，见下）。

| 格式 | 扩展名 | 说明 |
| --- | --- | --- |
| XMind | `.xmind` | 同时支持现代 XMind（zip + `content.json`）与 XMind 8（`content.xml`） |
| Markdown | `.md`、`.markdown` | 按标题层级还原成树，正文段落成为备注 |
| OPML | `.opml`、`.xml` | 大纲工具的标准格式，`_note` 成为备注 |

入口有两个：列表页的「导入」按钮，或者直接把文件拖到列表页上。

**限额**（超出会明确报错，不会静默截断）：

| 项 | 上限 |
| --- | --- |
| 文件本身 | 50 MB |
| 解压后总量 | 200 MB |
| 单个条目解压后 | 50 MB |
| 压缩包条目数 | 4096 |
| 节点总数 | 20000 |
| 单个标题长度 | 2000 字 |
| 单次导入还原的图片 | 100 张 |

这些上限防的是「zip 炸弹」和节点爆炸，不是随便定的数字。真导不进来时，先看
文件是不是超过了其中某一条。

**导入的边界**：

- XMind 里节点上的**图片**会一起还原（上传到站内，之后不依赖原文件）；
- **备注**会保留，主题上显示备注入口；可通过「插入 → 备注」编辑，导出 Markdown / OPML 时会作为正文带出来；
- **关系线、概要、边界**会还原并画在画布上，之后可以在右侧面板的「结构」页改名或删除；
- **联系线**支持双击线条或文字编辑，Enter 或失焦保存、Esc 取消；单击联系或结构面板中的条目，可以设置颜色、线宽、直线/曲线/折线、实线/虚线/点线，以及无箭头、正向、反向、双向。概要保留跨分支选区，向外避让主题；相同范围重复点击会定位已有概要。
- 支持的标记（marker）会显示在主题前，也可以在「标记」面板修改；标签以 badge 显示在主题框下方并可编辑；
- 带密码的 XMind 不支持：会明确提示「请先去掉密码」，不会被当成「文件损坏」。

管理员可以整体关闭导入功能。

## 8. 导出

点工具栏「导出」，左侧是参数，右侧是**真实预览**——预览就是最终结果，不是示意图。

### 七种格式

| 格式 | 适合 | 注意 |
| --- | --- | --- |
| SVG | 印刷、二次编辑、无限放大 | 矢量，体积小 |
| PNG | 贴到文档、聊天工具 | 支持透明背景 |
| JPEG | 需要白底的场合 | 没有透明通道，会填白 |
| PDF | 打印、发给不用电脑的人 | **文字是位图，不可选中**（见下） |
| XMind | 发给用 XMind 的同事、继续在 XMind 里改 | 层级、备注、标签、标记、联系、外框、概要都带过去 |
| Markdown | 转到笔记工具、Wiki | 只保留文字与层级 |
| OPML | 导入其他大纲工具 | 只保留文字与层级 |

### 参数

| 参数 | 说明 |
| --- | --- |
| 内容范围 | 当前画布 / 全部画布（只有一张画布时「全部」是灰的）。选全部会打成一个 zip，每张画布一个文件。**对图片、PDF 与 XMind 有效**——Markdown / OPML 导的始终是当前画布 |
| 倍率 | 1× / 2× / 3× / 4×，或自定义（0.5–8，保留一位小数）。倍率只影响清晰度，不改变纸张大小 |
| 留白 | 无 / 24px / 40px / 80px |
| 长宽比 | 跟随内容，或 16:9、4:3、1:1、9:16（竖屏）。选固定比例会加留白把内容放进框里 |
| 透明背景 | 仅 PNG |
| 边框 | 无 / 细描边 / 红 / 橙 / 绿底 / 蓝底 |
| 显示日期 | 在角落加上导出日期 |
| 品牌标识 | 右下角的落款。文字默认取「网站设置 → 品牌标识文字」，勾上之后可以当场改；留空则不打印 |

### 关于 XMind

导出的 `.xmind` 是 **XMind 2020 之后的格式**，XMind 8 打不开（它需要旧版 XML）。
层级、备注、标签、标记、超链接、图片、联系、外框、概要都会带过去。待办、任务、附件、贴纸、插画和公式使用 wmind 扩展，保证本项目往返，外部 XMind 不保证识别；配色与形状
按每个主题写进文件，所以打开后看起来和这里一样。

代价是：**在 XMind 里换主题不会改变这张图的外观**——每一项样式都是显式值。
如果打算到 XMind 里重新配色，导出 SVG 或者直接在 XMind 里新建更合适。

字体不写进文件：这里存的是「无衬线 / 衬线 / 等宽」这样的族，而 XMind 记的是具体
字体名。硬塞一个字体名，到了没装这个字体的机器上反而更难看，所以交给 XMind 决定。


### 关于 PDF

PDF 走的是**位图**方案：整张导图先栅格化，再包进 PDF 容器。好处是不用装字体，
中文在任何设备上都正常显示；代价是**文字不可选中、不可搜索**。

需要可编辑的文字请导出 SVG。这一点在导出对话框里也写着，不会让你拿到文件才
发现。

### 大图的限制

浏览器画布单边上限 16384 像素。超过时导出会拒绝并提示，解决办法：

- 降低倍率；
- 改用 SVG（矢量不受这个限制）；
- 分画布导出（把大图拆成几张）。

2× 以上的大图会先提示「生成可能较慢」，属正常现象。

如果导图里有外链图片，导出时会尽量内嵌；实在取不到的会提示「N 张图片未能内嵌，
导出后仍指向原地址」。

管理员可以整体关闭导出功能：关闭后编辑器工具栏与分享页都不再出现「导出」入口
（站点级开关优先于单条分享链接的「允许下载」）。

## 9. 分享

分享产出的是一个**公开只读链接**：拿到链接的人不用登录就能看，不能改。

### 创建

在列表页或编辑器顶部点「分享」→ 填参数 → 「创建链接」→ 复制。

| 参数 | 说明 |
| --- | --- |
| 访问密码 | 留空表示不要密码；可随机生成 4 位大小写字母与数字，也可手填至少 4 位，打开的人要先输 |
| 有效期 | 永久，或 1 / 7 / 30 / 90 / 365 天 |
| 允许下载 | 关闭后分享页不显示导出入口 |
| 显示备注 | 关闭后**服务端**把备注从响应里剥掉，不是前端藏起来 |

**关于「允许下载」**：它降低的是门槛，不是访问控制。分享页需要把文档结构下发到
浏览器才能折叠和缩放，所以懂技术的人仍然可以通过开发者工具看到内容。真正的
访问控制只有两样：密码，和不分享。

### 管理

「我的分享」页列出你发出去的所有链接，显示访问次数、过期时间和访问密码。
密码可反复查看、复制，关闭窗口、刷新或对方访问分享后不会消失；导图里的分享弹窗也可以查看。
复制链接会附带 `?psw=...`，对方打开后自动填入密码框，仍需主动提交。
旧链接若显示「原密码不可查看」，可点「重设密码」设置一次，之后即可查看和复制。

分享访问码明文保存在数据库及备份中，请勿复用登录密码。

随时可以**撤销**——撤销后地址立即失效，已经发出去的链接也打不开，但记录与
访问次数会保留。

同一张导图的分享链接数量有上限（默认 20 条），撤销几条就能再建。

### 对方看到什么

- 不需要登录，也不需要装任何东西；
- 有密码的先看到密码框；
- 分享页底部显示「由某某分享于某时」，以及「某时后失效」；
- 链接失效（被撤销、已过期、导图被删除）时显示统一的失效页，**不区分原因**——
  这是刻意的，避免泄露「这张导图存在过」。

管理员可以整体关闭分享。关闭后**所有**历史链接立即失效，列表页与编辑器里的
「分享」按钮也一起消失；重新打开后恢复。

## 10. 回收站

删除的导图先到回收站，不会立刻消失。列表里能看到「删除于某时」。

- **恢复**：回到列表，内容原样回来；
- **彻底删除**：单张永久删除，不可恢复；
- **清空回收站**：一次删光，会二次确认。

导图在回收站期间，它已有的分享链接**打不开**（显示统一的失效页）；恢复之后
这些链接重新可用，访问次数也还在。

**回收站不会自动过期**——放多久都在，直到你手动清理或清空。磁盘空间紧张时，
记得来这里看一眼。

## 11. 个人设置

| 项 | 说明 |
| --- | --- |
| 昵称 | 显示在分享页署名处 |
| 邮箱 | 用于登录（用户名也能登录）；改成别人已占用的会报错 |
| 密码 | 改密码要先输入当前密码；改完**保留当前设备**，其它设备上的登录会被踢下线 |
| 头像 | 上传图片，服务端居中裁剪成正方形、缩放到 256×256 |
| 双因素认证 | 设置验证器、下载或重新生成恢复码、停用 2FA |
| 外观 | 浅色 / 深色 / 跟随系统 |
| 语言 | 跟随浏览器 / 中文 / English |

外观与语言都存在**你自己的浏览器**里，换设备要重新选。

### 设置双因素认证

1. 点「设置双因素认证」，输入当前密码，点「生成二维码」。
2. 用验证器扫描二维码，或手动输入显示的密钥。设置十分钟内有效；验证成功前不会启用。
3. 输入应用中的六位验证码，点「验证并启用」。
4. 下载并保存十个恢复码，再点「已保存恢复码」。恢复码只显示这一次，每个只能使用一次；请与验证器分开妥善保存。

启用或停用会使旧会话失效，当前设备继续保持登录。重新生成恢复码和停用都需要当前密码及有效验证码或恢复码；重新生成后所有旧恢复码立即失效。管理员重置密码不会关闭双因素认证，同时丢失验证器和恢复码时没有自动恢复入口。

## 12. 管理后台

只有管理员能看到左侧的「管理概览 / 用户管理 / 网站设置」三项。

### 概览

四张卡片：用户总数、活跃用户、导图总数、存储占用；下面一条近 14 天新增的走势
（用户与导图两条线），再下面是**最近 8 条管理操作**。

审计日志只增不改，记录谁在什么时候改了什么。一期没有独立的审计页，也不支持按
时间或操作者筛选——最近操作只在概览页露最后 8 条，完整记录走接口
`GET /api/v1/admin/audit-logs`。

### 用户管理

| 操作 | 说明 |
| --- | --- |
| 新建用户 | 直接指定用户名、邮箱、密码与角色 |
| 改角色 | 普通用户 / 管理员 |
| 禁用 | 禁用后无法登录，数据保留 |
| 重置密码 | 生成一串一次性明文新密码，**只显示这一次**，请立刻转交给用户 |
| 删除 | 账号与其导图一并不可访问（导图不进任何人的回收站） |

两条硬约束：不能降级或删除**最后一个管理员**，也不能删除自己。管理员也不能在
后台重置自己的密码——请走「个人设置」。

### 网站设置

| 分组 | 设置项 | 默认 |
| --- | --- | --- |
| 站点 | 站点名称、Logo、简介、ICP 备案号、对外地址 | `wmind` |
| 注册与登录 | 是否开放注册、新用户默认角色、密码最小长度、登录失败上限、锁定时长 | 开放 / `user` / 8 / 5 次 / 15 分钟 |
| 限额 | 单用户导图上限（0 表示不限）、上传文件大小上限 | 0 / 10 MB |
| 功能开关 | 导入、导出、用户模板 | 全开 |
| 分享 | 是否开放分享、默认有效期、默认允许下载、强制密码、单图链接上限 | 开放 / 永久 / 允许 / 否 / 20 |

改完立即生效，不需要重启。

### AI 设置

在「网站设置 → AI」配置 OpenAI 兼容的 Base URL、API Key、Model，再打开「启用 AI 功能」。默认关闭，关闭时所有用户的生成入口隐藏，生成接口也不可用。Base URL 按 Provider 提供的完整前缀填写（例如包含 `/v1`），不自动补版本路径。

「思考等级」默认「不传」，完全省略 `reasoning_effort`，由 Provider 与模型使用自身默认值；可显式选择 `none`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`。并非所有模型都支持全部等级，不支持时会提示调用失败，不自动降级或重试。

密钥留空保留已保存的值；需要清除时先关闭功能，再勾选「清除密钥」保存。追加提示词只能查看，会放在用户输入与全部附件之后，用于约定导图输出结构。密钥仅保存在服务端，不返回浏览器；更换服务器有效加密密钥后需重新填写 Provider 配置。

**关闭注册**之后：登录页的注册入口消失，直接访问注册页只看到提示，注册接口
返回「站点已关闭注册」——而且这个判定排在限流之前，探测的人不会因为反复尝试
被误判成「请求太频繁」。

**关闭分享**之后：所有历史链接立即失效，已登录用户也看不到「分享」按钮。

### 审计日志

见上面「概览」：只展示最近 8 条管理动作（新建用户、改角色、禁用、重置密码、
删除、改设置）。普通用户的日常操作不进这张表。

## 14. 常见问题

**忘记密码了怎么办？**
找管理员重置。一期没有自助找回，也不发邮件。拿到一次性新密码后请立刻改掉。

**登录页没有「立即注册」？**
管理员关闭了注册。需要账号请联系管理员。

**刷新后改动丢了？**
先看是不是关了标签页——重新打开那张导图时会提示恢复本地草稿（保留 7 天）。
如果是「保存失败」，检查网络后点工具栏的「重试」。

**提示「这张导图已在别处修改」？**
同一张图在两个标签页或两台设备上同时改了。选「另存为副本」最安全；选「保留
我的版本」会覆盖另一边的修改。

**导出的 PDF 里文字选不中？**
这是位图方案的结果，不是 bug。需要可编辑的文字请导出 SVG。

**导出报「超过浏览器上限」？**
降低倍率，或改用 SVG，或把内容拆到多个画布分别导出。

**分享链接打不开？**
可能是：已被撤销、已过期、导图被删了、或者管理员关闭了分享功能。这四种情况
都显示同一个失效页，需要向分享者要新链接。

**分享页看不到导出按钮？**
分享者在创建时关掉了「允许下载」。

**导入的 XMind 里有些东西不见了？**
支持的标记会显示在主题前；标签以 badge 显示在主题框下方并可编辑，备注通过主题上的入口打开（导出 Markdown 时会带出来）。关系线、概要、边界和图片会正常显示。详见下一节。

**能用手机吗？**
界面是响应式的，浏览器能用。但没有专门的移动端 App，窄屏上编辑体验一般，
建议查看与轻改。

**两个人能同时编辑同一张图吗？**
不能。一期没有实时协作，同时改会撞上冲突对话框。

## 15. 一期做不到的事

如实列出来，省得你花时间找入口：

| 做不到 | 说明 |
| --- | --- |
| 实时协作 | 同一张导图同时只能一个人改，第二个人会撞冲突对话框 |
| 指定用户共享 | 分享只有「公开链接」一种，没有「只给某人看」 |
| 自助找回密码 | 没有邮件服务，只能管理员后台重置 |
| 邮箱验证 | 注册即生效，不发验证邮件 |
| Zone / 录音 | 暂未提供 |
| 概要 / 边界的高级用法 | 不支持拖动改覆盖范围；联系线已支持样式、箭头和走向调整，但不自动避让中间主题 |
| 演说模式 | 面板里那一页写着「一期暂未开放」 |
| 服务端导出 | 超大图没有服务端兜底渲染，只能降倍率或改 SVG |
| 版本历史 | 没有「回到某个历史版本」，只有撤销与回收站 |
| 图库、甘特图 | 一期不做 |
| 客户端 App | 一期不做；接口已按无状态认证设计，二期可接 |

这些不是「忘了做」，是明确划在一期之外的。要评估二期能不能补，看
[08-开发路线图](./08-开发路线图.md) 第 11 节。
