# wmind 开发文档

wmind 是一套可私有化部署、数据自主可控、体验对标 XMind 的 Web 思维导图系统。

本目录是项目的**需求与设计基线**。任何实现与本文档冲突时，以文档为准；需要改文档时，走 [09-技术决策记录](./09-技术决策记录.md) 第 5 节的变更流程。

## 一句话概览

| 维度 | 结论 |
| --- | --- |
| 后端 | Go 1.23 + Gin + PostgreSQL 16（pgx + sqlc），模块化单体 |
| 前端 | React 19 + TypeScript + Vite + shadcn/ui + lucide-react |
| 编辑器 | 自研 SVG 渲染 + 自研布局引擎（8 种结构） |
| 数据格式 | 自有 `.wmind` JSON，结构对齐 XMind `content.json`，存 JSONB |
| 导入 | XMind（现代 + XMind 8 双格式）、Markdown、OPML |
| 导出 | PNG / JPEG / SVG / PDF / Markdown / OPML |
| 模板 | 8 个内置模板（思维导图、逻辑图、括号图、组织结构图、树形图、时间轴、鱼骨图、树型表格） |
| 主题 | 10 套配色（缤纷 5 + 经典 5）+ 形状/线条/字体自定义 |
| 后台 | 用户管理 + 站点设置（含是否开放注册） |
| 部署 | `docker compose up -d` 一条命令 |
| 预留 | 客户端 App（无状态认证、版本化 API、设备表、增量同步接口） |
| 一期不做 | 实时协作、分享链接、评论、甘特图、演说模式、AI 生成、客户端 App |
