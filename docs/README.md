# wmind 开发文档

wmind 是一套可私有化部署、数据自主可控、体验对标 XMind 的 Web 思维导图系统。

本目录是项目的**需求与设计基线**。任何实现与本文档冲突时，以文档为准；需要改文档时，走 [09-技术决策记录](./09-技术决策记录.md) 第 5 节的变更流程。

## 一句话概览

| 维度 | 结论 |
| --- | --- |
| 后端 | Go 1.25 + Gin v1.12 + **SQLite（`modernc.org/sqlite`）/ PostgreSQL 16（pgx）双方言** + sqlc 双 target，模块化单体 |
| 数据库 | **双方言由 `WMIND_DB_DRIVER` 选择，默认 SQLite**；本地开发用 SQLite（不需要任何数据库服务），线上两套 compose；无跨方言自动搬迁（见 ADR-015 / Q-11） |
| 前端 | React 19 + TypeScript + Vite + shadcn/ui + lucide-react，**纯 SPA** |
| 编辑器 | 自研 SVG 渲染 + 自研布局引擎（8 种结构）+ 只读查看器 |
| 数据格式 | 自有 `.wmind` JSON，结构对齐 XMind `content.json`，存 JSONB / TEXT |
| 导入 | XMind（现代 + XMind 8 双格式）、Markdown、OPML |
| 导出 | PNG / JPEG / SVG / PDF / Markdown / OPML |
| 模板 | 8 个内置模板（思维导图、逻辑图、括号图、组织结构图、树形图、时间轴、鱼骨图、树型表格） |
| 主题 | 10 套配色（缤纷 5 + 经典 5）+ 形状/线条/字体自定义 |
| 字体 | **默认思源黑体（Noto Sans SC，SIL OFL 1.1，可自由分发）**；内置 4 个字体族标识符（黑体 / 宋体 / 等宽 / 跟随系统），按 `unicode-range` 分片按需加载，不依赖外部 CDN（ADR-016） |
| 分享 | **公开只读链接**：可设访问密码、有效期、是否允许导出、是否显示备注 |
| 邮件 | **一期不接入**：账号找回由管理员后台重置密码承担；二期按归档设计接入 SMTP（ADR-012 / ADR-014） |
| 外观 | 浅色 / 深色 / 跟随系统三档 |
| 后台 | 用户管理（含重置密码）+ 站点设置（注册开关、分享策略、资源限制） |
| 部署 | **两套 compose**：默认 SQLite 两容器（`docker compose up -d`），可选 PostgreSQL 三容器（`-f docker-compose.postgres.yml`）；**一期零外部依赖（含出站）** |
| 预留 | 客户端 App（无状态认证、版本化 API、设备表、增量同步接口）；邮件服务（`user_tokens` 表 + 接口与错误码编码已预留）；跨方言数据迁移（二期 `wmind db migrate`） |
| 一期不做 | 实时协作、指定用户共享（ACL）、评论、甘特图、演说模式、AI 生成、图库、客户端 App、**邮件服务**、**跨方言数据搬迁** |
