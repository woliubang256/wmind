# 桌面客户端更新日志

`mygo build` 从这里取每个版本的发布说明写进更新清单（apps 弹窗里显示的就是
这一节）。格式要求：每个版本一个 `## <版本号>` 标题，版本号与 `VERSION` 一致。

## 1.1.3

- 新增 Linux 版本（.deb / tar.gz + install.sh / PKGBUILD）。
- 日志支持滚动并记录启动、接口调用与云端连接过程；启动失败会弹窗说明原因。
- 修复 Windows 启动即退出（备份维护锁）与 WebView2 缺失时的静默失败。
- 修复首次同步必定失败、令牌过期后同步失败、缩略图不显示、仅打开也会改更新时间。
- 修复编辑主题时输入框不随内容变大；界面字体改为系统字体优先，弹窗与下拉明显更快。

## 1.1.2

- 修复 Windows 版启动即失败的问题（备份服务的跨进程维护锁在 Windows 上没有实现）。

## 1.1.1

- 启动失败时会弹窗说明原因并给出日志路径（`startup-error.log`），不再出现「双击没反应、也没有报错」。
- 修复启动失败后残留进程占用单实例锁、再次点击图标无反应的问题。

## 1.1.0

- 登录云端支持两步验证（动态码或恢复码），登录后顶栏显示账号昵称与头像，并记住上次的服务器与账号。
- 「网站设置」在客户端内直接读写服务器配置；登录后分享功能归服务器管理。
- 新增关于弹窗（项目介绍、版本、检查更新、项目地址、部署说明）与快捷键速查。
- 界面字体改为系统字体优先，弹窗与下拉几乎即时打开。
- 修复主题文字不居中、缩略图显示为问号或不铺满卡片、云端登录失效被误判为退出登录。

## 1.0.0

桌面客户端首个版本。

- 本地优先：断网也能完整编辑、导入导出、使用主题与模板，数据保存在本机。
- 可连接自托管服务器：导图带「本地 / 云端」标识，本地可上传云端，删除状态双向同步。
- 冲突时提供「保留我的 / 放弃我的 / 另存副本」三种处理，任选其一都不丢数据。
- AI 与备份可离线配置：AI 填本机 Provider，备份可指向本地目录、S3 或 WebDAV。
- 无系统标题栏，窗口顶栏即标题栏；支持 Intel 与 Apple Silicon 两种安装包。
