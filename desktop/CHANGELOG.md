# 桌面客户端更新日志

`mygo build` 从这里取每个版本的发布说明写进更新清单（apps 弹窗里显示的就是
这一节）。格式要求：每个版本一个 `## <版本号>` 标题，版本号与 `VERSION` 一致。

## 1.0.0

桌面客户端首个版本。

- 本地优先：断网也能完整编辑、导入导出、使用主题与模板，数据保存在本机。
- 可连接自托管服务器：导图带「本地 / 云端」标识，本地可上传云端，删除状态双向同步。
- 冲突时提供「保留我的 / 放弃我的 / 另存副本」三种处理，任选其一都不丢数据。
- AI 与备份可离线配置：AI 填本机 Provider，备份可指向本地目录、S3 或 WebDAV。
- 无系统标题栏，窗口顶栏即标题栏；支持 Intel 与 Apple Silicon 两种安装包。
