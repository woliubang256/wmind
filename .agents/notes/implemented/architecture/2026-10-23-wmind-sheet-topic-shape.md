# Agent Note: 当前画布统一主题形状

Status: implemented

## Problem

“形状与结构”把节点级形状和画布级布局放在一组，用户选形状时只有当前节点变化，选布局却整张画布变化。用户确认二者作用于当前画布，且新增主题继承形状，颜色、字体等其他样式保留。

## Decision

画布增加可选 `topicShape`，只在用户主动选形状时写入，缺失时沿用现有主题和节点形状。该值在布局解析后、测量前统一覆盖主题形状，包括中心、分支、子主题及自由主题；折叠后代在展开时自然继承。保留原有节点显式字段，撤销能完整还原，不批量改写颜色或字体。

命令只修改当前画布的一项，重复选值不新增历史。界面将全局形状与布局放在选中节点编辑区之前，并说明作用范围。统一走布局输出，让预览、SVG/PNG 和 XMind 导出复用实际形状。XMind 导出对布局未测量的折叠后代补齐解析样式，不遗漏全局形状。

旧文件不迁移，新增字段通过原生解析与保存往返；另一个画布不受影响。概要、边界、联系是附属结构，保留各自的形状与样式。

## Alternatives considered

- **批量写已有节点形状。** 使用已有命令最简单，也能立即让当前画布一致；但新增、粘贴、导入的主题还要逐入口补继承，折叠与自由主题容易漏掉。
- **复制完整主题到 `themeOverride` 并改角色形状。** 能复用主题模型，但会同时冻结配色等其他继承值，之后切换文档色板可能失效，偏离只改形状的范围。

## Testing

- 复现单选后只改一个节点的问题，修复后全部主题统一，其他样式保持。
- 其他画布不受影响，新建主题及折叠后代继承，重复应用不增加历史。
- 撤销重做、原生解析、保存刷新与导出形状一致，旧文件缺失字段时不变。
- 相关命令、原生解析、布局、导出及语言包 308 项单测通过；浏览器脚本覆盖真实单选复现和完整操作。

## Consequences

统一形状可能改变测量尺寸与整图排布，这是用户主动选择的结果。旧版客户端不认识新可选字段；XMind 导出使用已解析形状写入各节点，保证对方能看到一致的图形。
