# Agent Note: 思维导图分散端点与圆角分叉

Status: implemented

## Problem

所有分支从中心主题左右边缘的中点引出，分支多时挤成两束，且根到主分支的间距与普通子主题相同，曲线显得陡。用户提供 XMind 截图并确认：中心主题沿外缘分散出线，主分支自然展开，子主题用短横线与圆角分叉。

## Decision

只调整 `mindmap` 的父子连线。布局沿左右各半边按主分支实际方位分配端口，端口使用与 SVG 图形一致的轮廓相交算法；仅下划线使用实际线段的左右端点。曲线主分支从对应端口向外展开，末端水平接入主主题。根到一级分支使用独立间距（普通 128px，紧凑 80px），深层保留既有间距。

曲线子主题复用已有圆角括号路径，短横线与同一父级共享的竖向分叉构成连接。显式直线、折线、无连线及颜色、线宽、箭头继续尊重用户选择。其他布局与联系线不改。

布局给 `EdgePath` 增加可选 `curveControls`，不保存到文档。控制点限制在端点的包围盒内，收尾平移同时平移控制点，保持视口裁剪与导出范围成立。编辑器、只读查看器和 SVG/PNG/PDF 导出共用路径生成器。

## Alternatives considered

- **仅增加根到分支的间距。** 改动最少，可以缓解陡曲线；但分支仍共享一个点，不能得到参考图的扇形展开。
- **在渲染层根据父级 id 或主题名称猜测。** 无需调整布局契约；但导出、预览与编辑可能不同步，也破坏布局负责几何的边界。
- **所有深层分支都使用独立发散端口。** 每条线都分开，能完全避免共享端点；但参考图对子主题采用的是共同圆角分叉，深层也发散会增加视觉复杂度。
- **按同侧分支序号均分半圆角度。** 端口间隔整齐，等高子树下效果稳定；但子树高度不均时，序号与主主题实际位于中心上方或下方的关系会错位，曲线会从顶部端口朝内部折回。实际方位求交保证曲线从端口向外。

## Testing

- 先复现 20 个主分支在每侧共点的问题，再验证左右端口有序、互不重合、端点贴轮廓。
- 不同形状、紧凑模式、单分支、左右不平衡、折叠及新增后仍生成有限且正确的几何。
- 子主题为圆角分叉，显式线型与样式保留；其他结构、概要与联系线回归通过。
- 预览及 SVG 导出使用同一路径，浏览器截图核对少量和大量分支。
- 布局、路径、裁剪与导出单测覆盖不均匀子树的向外出线；`editor-appearance.mjs` 的 24 项浏览器检查覆盖三个修复，以及 20 分支的路径、折叠和保存。配色、附属结构、拖拽和视口裁剪的 81 项浏览器回归通过。

## Consequences

已有思维导图会按新几何重绘，文件中不写入派生端点；根与一级分支距离增加，缩放到适应时会重新计算大小。圆角分叉有重合的共享短横段，保持原颜色与线宽，不将不同颜色的子主题强制合并为一个 SVG 路径。
