# Agent Note: 概要清空标题的保存语义

Status: implemented

## Problem

概要画布输入框会提交空字符串，但改名命令和结构侧栏拒绝空标题，用户清空后仍看到旧文字。概要已有矩形命中、直接选中、双击与 F2，拒绝空标题最初用于防止空白结构无法再编辑的理由已不成立。

## Decision

概要与联系允许真实保存空标题；纯空白在命令入口 trim 为 `''`，同步修改画布级与父主题级副本。保留概要矩形、括号和命中范围，不把占位文案写入标题。空概要的可访问名称使用本地化的「概要」，画布仍没有文字。

命令与结构侧栏共享空标题语义；渲染的最小矩形保留交互区域，空标题仍可双击或 F2 重新编辑。边界拒绝空标题的既有规则保持独立。

## Related decisions

- [附属结构](../../implemented/architecture/2026-10-22-wmind-annotations.md)：部分替代其拒绝概要空标题的决定，保留双位置存储和边界改名行为。
- [概要端点](../../implemented/feature/2026-10-23-wmind-summary-endpoints.md)：部分重叠，保留矩形命中、选区和概要端点身份。
- [联系编辑](../../implemented/feature/2026-10-23-wmind-relationship-editing.md)：部分重叠，复用已存在的空字符串提交语义。
- 其余概要布局、主题内容、导入导出架构笔记仅共享关键词；此次不更改范围、布局或容器格式。未发现同主题 proposed 或 rejected。

## Alternatives considered

- 保留旧标题可以避免空白结构难以发现，且不需要改变既有存储；但用户清空已是明确编辑动作，概要矩形仍可命中，此方案会静默丢弃用户输入。
- 清空时删除概要可以避免空节点，但会连带删除概要联系并改变结构，超出清空文字的含义，因此保留结构与 id。

## Testing

空字符串和纯空白命令测试先在旧实现上失败，再修复到通过。命令、渲染、概要布局和 XMind 往返共 79 项定向单测通过；独立接口夹具浏览器验收 8/8，覆盖 Enter、失焦、Esc、空矩形再编辑、F2、撤销重做、两处数据保存、侧栏清空和刷新。

## Consequences

清空只改文字，概要 id、范围、括号和联系端点保留。空概要缺少文字提示，但保留最小矩形、圆弧括号及本地化无障碍名称。JSON 和自有 XMind 往返保持空标题，不填入占位文字。外部 XMind 对省略空标题的显示取决于其实现，此次没有通过真实 XMind 应用验证。
