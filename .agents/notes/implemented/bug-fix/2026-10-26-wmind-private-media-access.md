# Agent Note: 导图媒体授权与旧上传引用兼容

Status: implemented

## Problem

上传目录把头像、导图图片和缩略图都作为永久公开资源。分享加密、撤销或停用属主后，知道图片地址的人仍可绕过这些控制取图。原生 SVG image 与 img 无法携带内存中的 Bearer 头；给图片地址加长期登录令牌也会扩大凭证暴露面。

历史上传文件没有独立属主记录。仅根据“某张自己的图包含这个地址”授权而不检查写入，会让攻击者把已知的他人地址写入自己的图后取得访问权。

## Decision

使用独立 issuer 的只读媒体 JWT，通过 HttpOnly、仅限 `/uploads` 的 Cookie 携带；令牌绑定刷新会话的数据库哈希，读取时检查会话与账号状态。它不能用于登录 API 或刷新，也不轮换刷新会话。

新文件名包含服务端确认的属主 ID 与随机资源 ID。旧文件仅允许已有属主导图或模板的引用；所有文档和缩略图写入阻止首次引用他人的新文件或没有已有授权的旧文件。私有响应使用 no-store，未知文件和跨属主访问统一不可见，公开头像使用严格文件名白名单。

分享响应只在内存中为实际图片地址增加分享授权信息；读取图片时重新检查分享当前状态、密码版本和当前剥离后文档中的实际图片引用。地址不写回属主文档，不向外部图片附加凭据。

后端访问日志对大小写不敏感的 `share`、`access`、`psw` 查询键全部脱敏，含重复或百分号编码的键；解析失败的查询整体脱敏。Markdown 的图片地址与 SVG 内嵌失败的回退地址移除本地媒体临时查询凭据，不能把短期密码证明长期带进下载文件；普通外链保持原样，成功的图片继续内嵌。

## Alternatives considered

- 新建媒体归属和导图关联表能提供直接索引及独立资产生命周期，长期规模化更合适；但必须同时迁移两数据库、旧备份的固定表集合、跨图与模板引用。本次使用服务端文件名和既有引用约束先建立严格边界，旧数据查询成本记录为重访条件。
- 前端统一 fetch 后转 Blob 能只使用现有 AT，减少 Cookie 契约；但画布、卡片、缩略图、模板、独立 SVG 和文档导出有多个消费者，单改画布会保留其他公开读路径，也容易把 Blob URL 写入持久化文档。
- 短期签名 URL 与原生图片标签自然兼容，但单纯离线验签不能满足立即撤权；每次回查权限后已与本方案同样需要会话和分享状态，故不在 URL 中放用户登录凭证。

## Verification

- 匿名、其他账号、伪造图片属主、首次复制旧图片地址到新文档均失败；头像公开且不存在的文件不回退 SPA。
- 当前属主可以使用新上传、旧导图、模板、复制图、缩略图和独立导出；改密后的替代会话继续可读。
- 旧媒体会话随登出、刷新轮换、改密、停用、删除失效，媒体令牌不能调用用户 API 或刷新接口。
- 分享图片需要当前有效分享授权且属于该分享可见内容，撤销、改密、过期、隐藏备注和账号停用后立即拒绝。

`TestMediaPrivateFilesRejectAnonymousAndOtherOwners` 先复现 GET/HEAD 与跨属主均为 200、复制地址到自己文档为 201；修复后拒绝。`TestMediaSessionRevocationAndIssuerIsolation` 覆盖退出、刷新、改密、停用、删除与三类凭据隔离；`TestMediaLegacyReferencesAndWriteBoundaries` 覆盖旧图、回收站、复制图、仅模板保留的引用、文档/缩略图注入与备注伪引用。`TestMediaSharesRecheckCurrentAccessAndOnlyRewriteLocalImages` 覆盖分享改密、撤销、当前文档移除图片、外链不加凭据及源文档不持久化临时 URL；`TestMediaPublicAvatarsAndFilesystemBoundary` 覆盖公开头像、未知文件和符号链接拒绝。service 测试覆盖多画布、折叠后代、自由主题和大整数不变。

日志与 Markdown/SVG 导出均先写泄漏复现测试，再修复至通过；访问日志保留图片路径与普通筛选参数但不含临时凭据，导出不会修改分享页内存中的可用图片地址。最终后端全量测试和 vet 通过；新依赖前端的全量验证见安全修复清单。

## Consequences

图片不再能凭永久直链绕过会话与分享撤权，头像保留公开用途。旧上传授权依赖已有文档/模板查询，有额外数据库读取成本；一次文档校验对相同地址去重、旧引用集合只查询一次。分享图片也要重新剥离和遍历当前文档，多图片大图存在 CPU 放大；若旧图规模或资源请求量扩大，应迁移索引化资源表，不能用过期权限缓存换性能。未关联到任何导图或模板的旧上传无从证明归属，不能恢复为公共资源，需要重新上传。已经下载的图片无法远程收回；外部网站图片不由本站控制。分享图片的查询凭据仅用于读取，后端查询日志脱敏、内置 Nginx 不记查询；不要在外层代理新增完整查询串日志。所有服务实例须同步升级，旧实例的静态路由仍会绕过新边界。
