# Agent Note: 编辑器面板入口归并与占位功能清理

Status: implemented

## Problem

工具栏与面板页签行都有收起入口，结构菜单也与样式页的“形状与结构”重复；演说页只展示未开放说明。重复入口占用工具栏，面板收起后的恢复位置与收起位置不一致。

## Decision

面板页签行右端保留唯一开关，复用 ToolbarButton 的图标与悬停、聚焦提示。收起后在相同右上角显示圆形悬浮展开按钮，开关后焦点交给替换后的按钮。移除工具栏的面板与结构入口，结构选择仍在样式页，继续使用同一命令。删除演说页签、占位内容与中英文文案。

此决定部分取代[面板](../../implemented/architecture/2026-10-19-wmind-canvas-panel.md)与[工具栏](../../implemented/feature/2026-10-23-wmind-toolbar-actions.md)的双结构入口，以及[多画布](../../implemented/architecture/2026-10-21-wmind-multi-canvas.md)保留演说占位的界面事实；样式、命令、历史和 ZEN 约定继续有效。

检索审计：上述三篇部分重叠，互链保留；个人设置入口归并笔记为不同控件，无需修改。其余面板样式、配色、标记笔记只消费面板，不持有开关位置决策。

## Alternatives considered

- 保留工具栏开关便于在页头发现面板，但用户已明确希望收起与展开集中在右上角，因此将入口移至面板处。
- 收起后保留整条窄侧栏能稳定布局，但会持续占用画布宽度；圆形浮动按钮满足同位置恢复并释放画布。

## Verification

- `node e2e/panel-controls.mjs` 验证工具栏无重复入口、四页签循环导航、样式页结构切换与撤销、唯一开关的坐标/圆角/悬停/焦点、375px 与 1440px 布局及预览/大纲/ZEN 切换；使用模拟认证与本地演示图，不修改服务端数据。
- `e2e/toolbar.mjs` 继续验证结构键盘与撤销，入口迁移到侧栏。

## Consequences

重复入口和未开放内容消失，画布通过悬浮按钮恢复侧栏。旧浏览器验收迁移到唯一入口；面板装卸会替换按钮节点，通过共享 ref 和下一帧聚焦显式移交焦点。结构选择需要打开样式页，工具栏不再提供快捷入口。
