# Agent Note: 删掉标题下面那行解释性副标题

Status: implemented

## Problem

登录页、导图列表、模板页的标题下面都挂着一行灰字：

| 位置 | 文案 |
| --- | --- |
| 登录卡片 | 「登录以继续使用你的思维导图。」 |
| 最近的导图 | 「继续整理正在进行的想法。」 |
| 模板页 | 「从模板开始，比从空白开始快。内置模板只读，点一下就能建出一张新导图。」 |
| 模板页分区标题右侧 | 「8 个内置起点」 |
| 模板页空状态 | 「在编辑器里点顶部的模板图标，就能把当前导图存成模板。」 |

这些字**不提供任何界面之外的信息**：标题已经说了「登录」「最近的导图」「模板」，
副标题只是把同一件事换个说法再讲一遍。代价却很实在——它们把视觉重心往下拽，
让本来该一眼看到的输入框、导图卡片、模板网格退到第二屏；模板页那两行更长的
说明还额外占掉一行高度，窄屏上直接导致第一行模板卡片被压到折线以下。

「8 个内置起点」尤其典型：它是**给开发者看的验收数字**，不是给用户看的信息。
用户不关心有几个起点，只关心有没有他要的那个。

## Decision

把这五处文案**连同 i18n 键一起删掉**，不是留着键改成空字符串：

- `auth.loginDescription`（含 `login-page.tsx` 里的 `<p>`）
- `maps.subtitle`（含 `recent-page.tsx` 的 `description=` 传参）
- `templates.subtitle`、`templates.section.basicHint`、`templates.empty.body`

删键而不是清空值，是因为 `locales.test.ts` 断言两份语言包**键集合完全一致**，
清空值会留下两个永远没人读的空键，下一个人还得再判断一次「这个键是不是漏填了」。
分区标题因此从 `flex justify-between` 的容器退回成一个裸 `<h2>`——它右边本来就
只剩那个数字徽标。

判断标准写成一句话，留给后面的人：**标题能说清的事，副标题不再说一遍。**
该规则作为项目级界面约束保存在 `AGENTS.md`：Avoid unnecessary secondary labels and descriptions. Let the layout do the explaining. 标题、分组、当前值和开关本身已表达的含义不再附第二层解释，也不将这些重复内容迁移到 tooltip；删除时同步清理中英文键和空容器。真正无法从布局推断的规则、作用范围、风险与权限影响保留，复杂规则按需展开，不牺牲可访问名称及图标操作提示。
界面上留下解释性文字的位置只有两类：

1. **用户会做错的地方**（危险操作的确认框、不可撤销的提示）；
2. **界面上看不出来的规则**（模板「只读」这种状态）。

其余一律删。模板页的「只读」信息移到了卡片上的状态标记，不再靠一段话解释。

### 后台与备份

网站设置不再使用页面级泛化提醒和各分组的解释性副标题。注册关闭、默认管理员与分享关闭的影响只在对应条件下各出现一次；同组多项风险同时存在时全部展示，避免删除重复提示后漏掉独立风险。资源限制的“0 表示不限制”只归属于允许零值的导图数量字段，不用于上传大小。

备份保留说明只解释手动/定时合计与远端清理边界；去重说明只解释登录和浏览不算内容变化。默认值与开关行为由当前控件表达，份数越界时才出现具体校验提示。已保存凭据的留空保留规则同组展示一次，不重复加密实现。恢复上传区只保留格式、大小、兼容性与密钥要求，覆盖风险仍保留在确认弹窗。

Cron 默认仅展示频率预设，选择自定义才显示五段规则、表达式与语法；已保存的非预设表达式自动展开，进入自定义不改写原值，切回预设才替换并收起。时区与五次执行预览始终可见。该收窄补充[后台备份](../feature/2026-10-24-wmind-admin-backup.md)的界面决定，不改变调度、归档、远端生命周期或恢复协议。

### 编辑器与分享

结构侧栏只在当前选区不满足新建要求时展示选区指引，不同时叠加“还没有”占位与操作教程；可新建时只展示列表和操作，空列表也由标题和新建按钮表达用途。附属结构的范围摘要与整个画布/选中主题的作用范围保留。彩虹分支仅保留开关标签，不另加同名小节标题。

分享弹窗删除下载开关的重复说明，创建结果缩为“链接已创建”，链接与复制操作继续直接呈现。此文案决定部分取代[分享默认与说明](../feature/2026-10-24-wmind-share-form-defaults.md)的下载提示，期限、权限、备注与异步草稿契约不变。

- `node e2e/secondary-copy.mjs` 的隔离接口夹具覆盖中英文、375/1280px、独立风险提示、30 份与去重关闭、预设/自定义切换、原文保留与保存刷新、Cron 错误、凭据规则不重复及恢复覆盖确认，以及编辑器选区提示、作用范围、彩虹开关撤销与分享结果，59 项通过；不使用真实远端或开发数据库。
- 设置字段、Cron 模型与语言包守卫共 19 项单测和 TypeScript 检查通过。
- 分享接口、附属结构命令与语言包共 34 项受影响单测通过；`share-defaults.mjs`、`panel-controls.mjs` 与 `summary-empty.mjs` 验证默认权限、异步草稿、面板入口、概要清空/撤销/刷新不受影响。

## Consequences

- 三个页面的首屏内容整体上移一行到两行，模板网格在 900px 高的窗口里能露出
  完整的第一行。
- 两份语言包各少 5 个键，`locales.test.ts` 仍绿。
- 空状态现在只剩一行「还没有自己的模板」。这是**故意**的：空状态的标题已经
  说明没有内容，下面那行「怎么建」属于「用户会做错的地方」以外的第三类——
  而它描述的操作（编辑器顶部的模板图标）在空状态下点不到，讲了也没用。
- 已知取舍：新用户第一次进模板页时，少了一句「模板只读」的说明。这个信息现在
  只在模板卡片上体现，需要用户看一眼卡片。如果后续反馈「不知道模板不能改」，
  应该改的是卡片的视觉表达，不是把副标题加回来。

## Alternatives considered

- **保留副标题但缩小字号 / 降低对比度。** 已经试过（原本就是 `text-sm
  text-muted-foreground`），问题不在样式而在「多一行字」，压暗之后仍然占位。
- **把副标题改成 tooltip。** 一个需要悬停才能看到、而且内容与标题重复的提示，
  比直接删掉更糟：用户多了一个发现成本，却没得到新信息。
- **只删文案、保留 i18n 键。** 见上，空键会让下一个人误判成漏填。
- **所有字段及 Cron 语法始终可见。** 熟悉 Cron 的用户可以少点一次；日常预设场景却为此承担整套规则的高度与阅读成本，因此只在自定义时展开，已有自定义值自动展示以避免隐藏异常配置。
