# Agent Note: 个人设置移除重复的外观与语言入口

Status: implemented

## Problem

全站右上角已有语言和外观操作，个人设置再次展示同样选项增加页面长度。语言入口使用面板的紧凑字号，与相邻用户名不一致。

## Decision

个人设置只保留账号和安全相关面板；右上角保留现有语言、外观及浏览器偏好持久化。语言选择器使用普通字号，触发器和选项均为 14px，不改变编辑器内紧凑下拉的字号。

本决定部分取代[语言入口笔记](../../implemented/architecture/2026-10-21-wmind-auth-locale-switcher.md)中保留账号页语言卡片的决定，其余首次访问和共享 store 的约束继续有效。主题、语言仍由原来的 store 管理，不清理已有偏好。

## Alternatives considered

- 保留个人设置卡片可以展示详细说明，也方便习惯在设置页寻找的用户；用户明确希望入口集中于顶栏，因此删除卡片，保留顶栏所有选项及持久化。
- 调大全部紧凑 Select 的字号能一次统一组件，但会改变编辑器侧栏的 11–12px 设计，因此仅切换语言组件的尺寸档位。

## Verification

- 个人设置无重复卡片，顶栏语言和外观可以切换且刷新保持。
- 浏览器计算的语言触发器和选项字号均为 14px，与用户名一致。
- 原有语言验收通过顶栏执行，避免依赖已经删除的 radio。

## Consequences

依赖账号页 radio 的既有验收需要同步迁移，不能通过删除原有验证绕过回归。
