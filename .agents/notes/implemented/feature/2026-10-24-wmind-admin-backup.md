# Agent Note: 后台定时备份与独立上传恢复

Status: implemented

## Problem

管理员需要在后台配置 Cron、WebDAV/S3 备份，并从手动上传的压缩包恢复。现有 CLI 快照与部署脚本没有后台调度、凭据管理和在线恢复生命周期。

## Decision

用户确认归档与数据恢复、远端存储、调度与 Cron 编辑、后台界面四个单元，分别提交代码与笔记。

后台使用版本化 ZIP：manifest.json 记录格式、数据库类型、迁移版本、加密密钥指纹、生成时间、逐文件 SHA-256 与大小；database 下按固定应用表顺序存储 JSONL；uploads 仅包含上传目录的普通文件。SQLite 与 PostgreSQL 仓储分别负责一致读事务和事务恢复，不在运行中替换数据库文件、不接受上传 SQL。恢复要求数据库类型、迁移版本与密钥指纹相符。

备份捕获数据库和文件时阻止新业务请求并排空在途请求；捕获结束释放，压缩与远端上传不占维护窗口。恢复先完整解包和校验，展示内容，再确认执行；维护期生成恢复前 ZIP，数据库事务内替换行、暂存旧上传目录并安装新文件，提交失败恢复文件目录。成功重载配置和认证缓存，轮换全部用户的 SessionVersion 并清除刷新令牌、待验证状态，使旧会话失效。进程崩溃跨越数据库与文件的提交边界不具备分布式原子性，保留恢复前 ZIP 和目录用于人工恢复。

备份目标只上传；恢复只处理管理员上传的 ZIP，不列举或下载远端对象。WebDAV 使用标准 HTTP 方法；S3 使用 AWS SDK 的 SigV4 与兼容 endpoint/path-style 配置。远端密码采用用途隔离 AES-GCM，API 仅返回是否已设置，空值表示保留。凭据、密钥、原始远端错误不写入审计或浏览器日志。应用环境配置不进入归档，跨机器须保留原有效 2FA/加密密钥。

调度采用标准五段 Cron（分钟精度）与 IANA 时区，默认关闭、Asia/Shanghai、每天 03:00。可视化字段与原始表达式双向同步，展示五次后续运行；同一进程任务互斥，不积压错过的运行。初期运行契约是单个后端实例，后台备份不宣称集群范围的文件维护互斥。作业结果与加密配置保存在专用 backup.* 设置键中，不暴露给通用设置或公开配置接口。

## Alternatives considered

- 原生 SQLite 文件与 pg_dump：现有 CLI 已证明其一致性且方便外部运维；后台热恢复需要重建所有连接或额外 pg 工具。后台采用事务内逻辑快照，CLI 不变。
- ZIP 中包含 .env：跨机器恢复最方便，但未加密归档同时暴露数据和解密密钥；环境密钥独立保管。
- 从备份源挑选恢复：减少下载上传步骤，但用户明确要求备份与恢复独立，因此不提供。

## Consequences

配置、用途隔离 AES-GCM 密文与公开脱敏模型、WebDAV 目录检查/递归创建/上传、S3 SDK 签名上传及写入后删除的连接测试已经实现。远端客户端拒绝重定向，错误不带上游响应或凭据。异步任务管理器提供捕获、压缩、远端上传、恢复前副本、事务恢复、缓存重载阶段，保存最近 20 次结果；调度逐分钟去重且不补跑。手动上传的暂存令牌绑定管理员，1 小时过期且使用一次。配置更新、连接测试、上传校验和后台作业共用互斥，不在任务中途改凭据。后台 API 已接入装配与管理员权限组，7 个接口同步 OpenAPI；网站设置通过常规/备份与恢复标签接入页面，两个表单独立，切换保留未保存草稿；备份支持连接测试、立即执行与最近任务，恢复仅上传并确认覆盖。Nginx 为备份路径单设 2 GiB/900 秒上限，不扩大普通上传额度。

核心协议见 [ZIP 归档与维护闸门](../../implemented/architecture/2026-10-24-wmind-backup-archive.md)。受影响测试验证两个远端协议的真实 HTTP 请求、认证与签名、上传内容、连接测试清理、失败及跨主机重定向拒绝；配置密文往返、错密钥拒绝、脱敏与保留已存凭据、Cron 时区和 DST 单调性通过。

维护捕获时间与数据量相关；本地空间至少容纳临时快照与恢复前归档。初期运行契约为单实例。数据库与文件系统不提供跨介质崩溃原子性，恢复前归档是最后退路。

管理器测试在独立 SQLite 与目录中验证完整 ZIP 上传/手动上传恢复、移除当前多余图片、恢复前 ZIP、旧 JWT 撤销、暂存令牌属主与重放拒绝、互斥、取消、无效 ZIP 不改数据及 Cron 分钟去重/禁用。认证缓存整批清理、通用设置忽略私有 backup.* 项共同构成恢复后的跨模块契约。

HTTP 集成测试使用真实 SQLite、登录 Cookie/JWT 与本地 WebDAV，覆盖配置保密、留空保留凭据、Cron 校验、后台上传与手动恢复、缓存重载、旧会话撤销、普通用户/未登录的七个入口拒绝、维护 503 与活性探针。路由和 OpenAPI 对等性通过。

Cron 编辑器采用五段独立规则：每值、间隔、多选指定值、连续范围和高级原文，保留无法简化的合法表达式，不因打开可视化编辑器损失 MON-FRI 等内容。预设只负责生成表达式，时区与存储草稿独立；变更去抖后由后端统一计算五次运行，避免前后端 Cron 方言漂移。模型的 12 个受影响测试已通过。

启动、每分钟调度和接收新上传时回收超过一小时的暂存目录；仅处理本应用生成的 stage/capture/before 加数字后缀目录，保留恢复前 ZIP、未过期目录及管理员自建目录。清理必须持有作业互斥。重启遗留暂存泄漏的复现测试先失败，修复后通过。SQLite 活库所在目录不能用作 uploads。

界面浏览器验收覆盖桌面、375px 窄屏、中英文、Cron 双向多选、无效表达式、凭据不回传、真实 WebDAV ZIP 上传、损坏文件拒绝、手动恢复确认、退出旧会话并重新登录查看安全副本。共享 Modal 以标题关联可访问名称，原生 dialog 的可访问名称缺失先由恢复流程复现；共享 Switch 增加圆点左定位，动画结束后圆点越过轨道的复现先失败再修复。Cron 多选折叠显示，避免默认展开 60 个分钟按钮。该破坏性 E2E 独立于默认套件并要求显式隔离环境标志。

交付验证：受影响后端包（backup、service、settings、httpapi、cmd/server）全部通过，SQLite 与临时 PostgreSQL 17 往返契约通过，方言门禁通过；前端相关 63 个单测、构建和隔离服务中的 20 项浏览器验收通过。两种远端协议使用本地 HTTP 服务验证；未使用真实云端凭据做现场联通测试。

竞态检测复现了任务启动返回值与后台 goroutine 同时读写同一 Job 的缺口。launch 将 Job 按值传给 worker，接口始终拿到独立的初始快照，后台更新只操作 worker 的副本。新增连续 25 次启动/完成的复现用例，使用 -race 校验。服务关闭先停止并等待调度循环，再等待作业，最后关闭数据库连接。

修复后备份管理器与新增 HTTP 场景的竞态检查通过（包含 25 次启动复现、完整恢复、互斥、取消和调度去重）；cmd/server 测试通过。临时服务使用 8099/5299，PostgreSQL 使用 55439，不重启用户现有的开发服务。
