# Agent Note: Insert 内容菜单与主题附加内容

Status: implemented

## Problem

加号错误地承载同级与子主题创建。用户确认改为两个独立按钮，Insert 支持备注、标签、待办、任务、网页/主题/文件/文件夹链接、附件、贴纸、插画、本地图片与公式，暂不实现 Zone 与录音。

## Decision

工具栏独立创建主题，Insert 按真实主题选区计算能力。无选区、概要选区或混合选区不偷偷作用到根主题；单值编辑要求单选，标签、待办和视觉内容允许批量设置。菜单显示禁用原因并支持键盘导航。

备注、标签、网页/主题链接、图片复用原字段。新的可选 content 字段承载待办、任务、便携文件/文件夹、附件、贴纸、插画与公式。文件和文件夹由浏览器选择并内嵌，下载恢复；文件夹打包 ZIP，不写无法访问的 file URI。单次文件总量限制 2 MiB，保存前校验文档不超过服务端 8 MiB 上限。图片使用已有 /files 上传，公式使用 MathJax 的 SVG 输出。所有内容参与测量、画布与图片导出，并支持编辑、移除和撤销。

主题主行按待办、标题、备注/链接入口排列。单个入口显示对应图标，两项合并为省略号；点击在 HTML 浮层查看纯文本备注或打开链接，并保留各自编辑入口。浮层支持 Esc、外部点击和键盘激活；平移缩放、切换画布/视图和预览状态后关闭，避免指向旧主题。预览允许查看与打开链接，隐藏编辑并禁止修改待办。导出仅绘制 SVG 图标与标签，不包含浮层。导入的 HTML 备注经白名单清洗后提取纯文本，查看与编辑共用转换，保存时遵循已有纯文本备注契约。只有接管内容事件的宿主才启用键盘入口，独立只读查看器和导出不生成无效按钮。标签以形状下方的 badge 换行，具体高度契约见[内容测量](../architecture/2026-10-23-wmind-topic-content-model.md)。

## Alternatives considered

- 为附件新增服务器上传存储可以降低文档体积，但需要新的私有资源授权、共享和导出协议；当前用户要求插入功能，便携内嵌文件可直接随导图保存与分享。接受 2 MiB 单批和 8 MiB 文档上限，超限在修改前报错。
- 只添加菜单项能快速还原截图，但无法完成操作；本次每项接入真实编辑与持久化，不显示未实现的 Zone 和录音。

- 单个入口直接打开编辑器或链接步骤更少，但备注无法只读查看、链接缺少就地修改入口；统一浮层让单项和合并项保持相同的查看与编辑入口。浮层放在 HTML portal 而非 SVG foreignObject，延续现有 Safari/导出兼容边界。

## Consequences

同级主题和子主题分别使用独立按钮，根主题禁用同级；加号是真正的 Insert。所有授权条目均有编辑、替换、移除与历史命令，Zone 和录音不展示。主题内容可见行与媒体参与布局和导出；标签、负责人和文件名同时进入字体加载与导出检测。内部主题链接展示目标标题，跨画布引用使用可点击链接入口。

单值编辑要求单选；标签、待办、贴纸、插画、图片支持批量。备注使用纯文本编辑。文件内嵌的代价是文档大小增加，文件/文件夹只支持浏览器下载恢复，不访问系统路径。新增字段通过 wmindContent 保证本项目 XMind 往返，不能保证外部 XMind 识别。

301 条集中定向单测通过；综合浏览器 21 项、概要端点 9 项以及原有工具栏/概要/路由/标记 55 项通过。SVG 与 PNG 实际下载并人工核对，生产构建通过，公式引擎为首次使用时加载的独立 chunk。

当前排版与浮层回归：194 项定向单测、insert-content 30 项浏览器检查通过；覆盖 HTML 备注、主行几何、标题编辑框、键盘返回、待办历史、预览只读、原文件/目录下载与 SVG/PNG。实际截图核对徽标位置、浮层和导出；SVG 合并入口仍保留超链接，生产构建与 verify-notes 通过。
