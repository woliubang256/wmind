# Agent Note: 作者保存画布视角，分享访客只保留临时交互

Status: implemented

## Problem

分享页只挂插件却未接折叠回调，也没有滚动条和显式缩放入口。作者的折叠字段已随主题保存，但缩放、位置和当前画布没有保存，分享与编辑刷新无法恢复同一初始状态。

## Decision

文档增加可选 viewState，保存 activeSheetId 与每张画布的世界坐标中心、zoom。旧文档缺省时适应内容；只在作者主动导航时更新，不在首屏布局或窗口改变时制造保存。视图更新走既有防抖自动保存和乐观锁，但不进入撤销历史；撤销内容时保留现有各画布视角，仍切到该历史所属画布。中心世界坐标而非像素偏移让不同尺寸的编辑和分享窗口保持同一观察位置。

分享页使用独立文档副本处理折叠，视口只存在组件内，刷新重新获取作者保存状态；复用同一滚动条与缩放数学，包含画布切换、适应全图和保持倍率的中心主题定位。图形导出使用当前访客折叠后的副本，不包含滚动条。

每次 `loadDocument` 增加独立代次，冲突丢弃与草稿恢复即使复用同一个画布 ID，也清理本地视角缓存并读取新状态。重载入口与首屏同样归一化安装到文档的 viewState，不能只校验活动 ID 而让坏数值绕过守卫。结构自动适应只响应同一加载代次内的主动结构变化，不覆盖重载带来的视角。撤销合并历史快照和当前各画布视角，再按恢复后的画布集合过滤，既保留最新导航，也能在反复删除/撤销时找回重新出现画布的视角。

布局等待字体 ready 并依赖字体 generation，避免在加载画面背后用回退字体测量后永久缓存错误宽度。只读交互通过专用插件和宿主回调执行，不挂编辑插件。

- [自动保存](../../implemented/architecture/2026-10-18-wmind-autosave.md)：部分重叠，复用状态机、草稿与冲突机制，主动导航现在也推进 revision，初次查看不写入。
- [只读查看器](../../implemented/architecture/2026-10-18-wmind-editor-svg-viewer.md)与[分享链接](../../implemented/architecture/2026-10-21-wmind-share-links.md)：保留只挂只读插件和服务端剥离边界，宿主接入临时折叠回调。

## Alternatives considered

- 仅存 localStorage：不增加文档保存和冲突，且实现简单；但其他访客无法读取作者状态，也不能跨设备，不能满足分享初始状态。
- 保存像素 x/y：可直接复用 Viewport；但编辑器侧栏和分享容器尺寸不同，会观察不同世界位置，因此保存中心世界坐标。
- 导航作为编辑命令：免费获得历史和保存；但撤销会先撤销滚动或缩放，破坏编辑撤销的含义，因此只推进保存 revision。

## Testing

- `view-state.test.ts` 先失败复现归一化丢视图、活动画布未恢复、反复删除/撤销丢视角，以及重载入口坏数值绕过守卫，修复后覆盖 14 项；`sheet.test.ts` 与 `canvas-navigation.test.ts` 共 30 项验证不进撤销、世界中心跨尺寸还原及导航数学。
- `e2e/share-canvas-state.mjs` 21 项使用全 API 拦截夹具验证保存/刷新、多画布、双轴滚动、定位保持倍率及访客零写入；375/1440 宽度无页面横向溢出，不写开发或线上导图。
- `e2e/canvas-view-reload.mjs` 先复现变结构重载自动 fit 并多余 PUT 的两项失败，修后 26 项验证同画布冲突丢弃、不同结构重载、草稿恢复和首屏/resize 零 PUT。
- `e2e/share-font-loading.mjs` 延迟真实字体样式表，先复现提前测字与缺少重算的两项失败，修后 8 项验证字体未就绪时不测量主题文字、就绪后首次布局与交互；`share-collapse-a11y.mjs` 25 项覆盖命名折叠按钮、Enter/Space、焦点保持与静态导出隔离。

## Consequences

作者和分享者看到相同的初始世界中心与倍率，容器尺寸不同只改变可见范围。主动导航也会产生文档版本，复用现有乐观锁处理多标签冲突；保存前刷新仍沿用离开保护和本地草稿。首屏/resize 保持只读，因此旧文档不会仅因查看新增字段。旧客户端不认识可选字段时可能丢失视角，内容本身不受影响。分享的“只读”不是防复制机制。
