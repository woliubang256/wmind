# Agent Note: 联系线画布编辑、样式与双端箭头

Status: implemented

## Problem

联系线只能通过结构面板改名。线条没有命中区域、双击编辑入口或样式控件，绘制时又忽略已有 lineEnd，箭头画在中心也会被主题遮住。

## Decision

Style 增加可选 lineStart（none / arrow / dot），保留 lineEnd 作为终点装饰。起终点独立存储，不交换端点 id：四种箭头方向可表达，主题继承语义也不变。原生文档解析、XMind 样式读取与写入同步支持。联系渲染读取 lineStyle / borderStyle / lineColor / lineWidth，默认保留曲线及虚线。端点按实际切线裁至主题矩形边缘，箭头沿端点切线绘制。联系路径和标题都纳入适应视野及导出包围盒。

编辑插件仅在编辑器挂载，用非缩放的透明宽描边命中细线；截住联系操作，避免触发框选与主题快捷键。单击激活结构面板，双击线条或标题打开绝对定位输入框；Enter 和失焦提交，Esc 取消，输入法组合期间不截 Enter。结构面板按明确点击或聚焦保持激活，避免悬停离开就丢失样式控件。预览、分享和导出没有编辑控件。

本决定部分替代[附属结构设计](../../implemented/architecture/2026-10-22-wmind-annotations.md)中联系不计入包围盒、仅面板编辑的选择；保留独立几何层、双层概要存储及原有命令历史。XMind 导出笔记继续负责容器和资源，不另造一套导出路径。没有同主题被否提案。

## Alternatives considered

- 反向箭头通过交换 end1Id / end2Id：不加字段即可支持单向；但双向无法表达，交换又会改变线条法线和弧的方向，故保留端点身份。
- SVG marker 画箭头：实现简短且自动跟随路径；现有父子线明确采用显式图形规避 Safari context-stroke 差异，联系沿用该取舍，按切线旋转图形。
- 只增加面板控件：复用现有改名输入框即可；无法满足画布双击编辑，也无法让空标题的细线容易点选。

## Consequences

- 颜色、线宽、实虚线、直/曲/折线及四种箭头方向即时生效，可撤销重做；联系允许清空标题，透明宽命中区使空标题线仍可再次编辑。
- 原生文档解析及 XMind 往返保留样式；旧文档没有 lineStart 时沿用主题或 none。XMind 标记字段仅验证本项目往返，尚未用外部 XMind 应用验收。
- 选中光晕与实际颜色分开，用户设置颜色时看到的是实际色；预览不带选中光晕。导出没有透明命中区、可聚焦入口或输入框。
- 端点按矩形边缘裁剪，非矩形主题采用保守外接框；联系路径暂不做全图障碍路由。
- 命令、布局、解析、导入导出、渲染及语言包相关 12 个文件共 252 条单测通过；生产构建通过。浏览器附属结构验收 30/30，覆盖空标题线、文字双击、F2、输入法、提交取消、样式、四种箭头、撤销重做、持久化和只读预览。
