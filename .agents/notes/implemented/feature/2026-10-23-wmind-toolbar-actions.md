# Agent Note: 工具栏操作提示与主题插入菜单

Status: implemented

## Problem

图标按钮缺少可见的操作说明，原有加号只创建子主题，同级主题只能通过键盘发现。
工具栏混用文字按钮与图标按钮，编辑、界面和文档操作散落，视觉分组不清楚。

## Decision

工具栏的结构与面板入口由[面板入口归并](../simplification/2026-10-24-wmind-panel-entry.md)部分取代：结构保留在样式页，面板唯一开关迁移到面板右上角并继续复用本篇的悬停、聚焦提示。其余工具栏与 Insert 规则继续有效。

工具栏按钮悬停或聚焦时在视口内显示提示，包含用途、已有快捷键，以及当前不可用的原因。不可用按钮保留键盘焦点并用 aria-disabled 阻止执行，提示通过 aria-describedby 关联。提示不参与页面布局，也不被编辑器 overflow 裁剪。

快捷键提示以现有键位表为准：折叠为 ⌘ / Ctrl + .，适应为 ⌘ / Ctrl + 1。操作提示不添加新的键盘动作。

工具栏操作入口统一为图标，按编辑、界面、操作三个可访问分组排列，组间用竖线区分。工具栏与组内按钮保持单行，窄屏通过原生横向滚动到达所有入口，组与按钮不压缩；文档标题仍可独立一行，避免工具栏占去多行画布高度。文档标题和预览状态继续显示文字；Insert 菜单条目保留名称并配图标。每个入口保留可访问名称，只有提示浮层展示用途与快捷键。

触摸滑动工具栏不触发悬停提示，指针取消时关闭已打开提示；鼠标悬停和键盘聚焦继续可用。Insert 浮层继续使用 Portal，随工具栏滚动重算锚点，入口完全滑出可视区域后关闭，不能停留在与入口无关的位置。

结构选择通过共享 Select 的可选 renderTrigger 接入 ToolbarButton。Select 仍拥有 ref、角色、展开状态、值和键盘事件；自定义入口必须转发这些属性，复用弹层与焦点逻辑。未提供 renderTrigger 的控件沿用默认文字入口。结构提示额外显示当前结构，避免图标入口隐藏选中值。共享控件的其余约束见[自绘表单控件](../../implemented/architecture/2026-10-22-wmind-custom-form-controls.md)。

原主题菜单决定（已由[Insert 内容菜单](2026-10-23-wmind-insert-content.md)部分取代；操作提示与焦点规则继续生效）：加号使用独立动作菜单，区分同级主题（Enter）与子主题（Tab），复用现有命令、历史和编辑焦点流程。根主题没有同级，菜单禁用该项并显示原因；既有 Enter 在根上创建子主题的键盘行为保持兼容。菜单支持方向键、Home/End、Enter、Esc 和点击外部关闭。执行动作时不把焦点还给触发器，避免抢走新主题的输入框焦点。

## Related decisions

- [键盘交互](../../implemented/architecture/2026-10-18-wmind-editor-keyboard.md)：复用命令并维护画布焦点。
- [删除冗余副标题](../../implemented/simplification/2026-10-22-wmind-drop-explanatory-copy.md)：本次提示解释图标动作与不可见的选区规则，不恢复与标题重复的说明。

## Alternatives considered

- 原生 title 无需额外组件，但键盘与触屏不可控，禁用状态说明也无法稳定验收，采用可访问的浮层提示。
- 用 Select 充当插入菜单可复用现有弹层，但它表达已选值，重复执行相同动作会被忽略；插入使用独立动作菜单。
- 为结构图标重写独立菜单可以完全控制入口样式，但会重复下拉的键盘导航、当前值和焦点返回逻辑；可选 renderTrigger 保留同一交互实现，并让编辑器复用操作提示。
- 窄屏换行让全部入口同时可见，但工具栏占去多行画布高度；用户要求移动端压成一行，因此选择保留按钮尺寸并横向滚动，代价是末尾入口需要滑动到达。

## Consequences

- 鼠标与键盘都能发现工具栏用途，禁用操作说明原因且不能执行。
- 浮层在视口内定位，并通过 Portal 避免被编辑器裁剪。
- 工具栏浏览器 12/12 用例验证纯图标入口、三组语义、菜单图标、结构键盘切换与提示、面板切换、375/1440px 布局，以及鼠标、聚焦、Esc、描述关联、插入层级、创建编辑焦点与撤销。画布 25 项及 Insert 21 项浏览器回归、27 条下拉/菜单能力/语言包单测、生产构建通过。
- 移动端浏览器回归先复现 375px 工具栏多行，再验证单行横向溢出、按钮不缩小和页面无横向溢出；旧工具栏验收同步为滚动后可达全部入口，TypeScript 构建检查通过。
- 禁用动作保留焦点，增加了键盘导航停靠点，以便用户发现原因。
