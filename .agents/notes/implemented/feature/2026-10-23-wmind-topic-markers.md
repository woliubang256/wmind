# Agent Note: 主题 Marker 面板与图标布局

Status: implemented

## Problem

导入和文档模型已有 Marker 数据，但主题不渲染标记，界面也没有添加入口。只在主题前画图会挤压或覆盖文字，固定宽度主题尤其明显。

## Decision

复用 import/markers.ts 的六类 42 个标记，不增加第二套 ID。工具栏打开 Marker 面板，点击图标作用于全部有效选中主题。同组至多保留一个，新图标替换旧图标；所有选中主题都已有同一标记时，再点统一移除，否则统一应用。允许清空选中主题全部标记，每次批量操作只写一条历史。

图标用共享 SVG 组件绘制，面板、画布和静态导出使用相同图形，避免平台 emoji 差异。measureTopic 为标记分配宽高，正常在文字前排列；固定宽度容纳不下标记与最小文字区时，标记换行置于文字上方。图片仍在标题内容下方。共享内容几何决定文字、标记、图片及编辑输入框位置，避免各算一遍发生覆盖。

## Alternatives considered

- 使用 emoji 可以快速覆盖所有分类，但不同系统的字形、颜色和宽度不一致，导出字体又可能缺失；采用显式 SVG 图形。
- 图标不计入节点尺寸，改动文件更少，但会覆盖文字且导出截断；标记参与内容测量。
- 多选时逐个切换标记可复用单节点逻辑，但混合选区会变成互换状态；批量动作统一应用或统一移除。

## Consequences

- 六类图标在选中主题前出现，同组替换、再次取消、清空、多选统一应用可撤销重做。
- 原生保存重开、既有 XMind 标记导入导出及 SVG 静态导出保留。
- 多标记、长标题、固定宽度、图片、不同文字对齐和编辑输入框互不覆盖。
- 中英文入口和名称一致，预览保留图标并移除编辑面板。

- 窄主题会增加高度，题名换行可能改变分支位置；未知原生标记保留并用问号显示，面板只创建已知标记。
- 主题内图标有白色衬底，避免红旗落在红色主题时隐形，面板保留原图形。
- 最终相关 15 个测试文件 230 条单测通过，覆盖命令、所有布局结构、内容几何、映射、原生解析、SVG/XMind 导出和语言包；四套浏览器验收共 55/55，通过多选、排版、输入框、持久化、清空撤销和预览等交互。生产构建通过，用户手册与界面验收入口同步更新。
